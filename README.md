# UnitySoloProject

유니티 개인 프로젝트입니다.

## 목표

1. Astar 알고리즘을 통하여 대상을 향해 이동하는 길 찾기
2. StatePattern을 통하여 상태별 움직임 제어
3. JSV를 사용하여 특정 상황 기록

## 배경

훈련을 하던 도중 병사 두 명이 사라졌다. 그와 동시에 괴물의 출현 소식이 들려왔다.
병사의 손실은 곧 군단의 전력 손실. 그들을 빠르게 찾으라는 지휘관의 명령에 의해 모든 병사는 주변을 탐색하기 시작했다.
적당히 시간이 지나면 발견될 것이라 믿으며 근처 숲에 잠시 들어왔는데,
하필이면 여기 있을 것이 뭐람.
아무튼, 발견하게 된 이상 저 병사들을 구출해 오지 않으면 안 된다.
비록 약하긴 하지만, 만약 실패하더라도 다른 병사들이 또 올 테니까...
